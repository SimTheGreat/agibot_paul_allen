Connect your Agibot to n8n workflows via webhooks.

Incoming Webhook (Robot API)

n8n can control the robot by POSTing to this endpoint:

POST http://localhost:5000/api/webhook/robot

Example payloads:

{
  "action": "emoji",
  "params": {"id": 90}
}

{
  "action": "tts",
  "params": {"text": "Hello from n8n!"}
}

{
  "action": "motion",
  "params": {"type": "wave_left"}
}

{
  "action": "mode",
  "params": {"mode": "stand"}
}

{
  "action": "workflow",
  "params": {"id": "workflow_id_here"}
}
