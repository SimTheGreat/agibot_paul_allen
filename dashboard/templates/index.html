n8n Webhook Connector

Connect your Agibot X2 to n8n automation workflows via webhooks. Trigger robot actions from any n8n workflow.

Incoming Robot API

n8n (or any service) can control the robot by POSTing to this endpoint:

POST http://localhost:5000/api/webhook/robot

Example payloads:

{
  "action": "emoji",
  "params": {"id": 90}
}

{
  "action": "tts",
  "params": {"text": "Hello from n8n!"}
}

{
  "action": "motion",
  "params": {"type": "wave_left"}
}

{
  "action": "mode",
  "params": {"mode": "stand"}
}

{
  "action": "workflow",
  "params": {"id": "workflow_id_here"}
}
